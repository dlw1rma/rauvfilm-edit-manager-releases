# 루카스프로덕션 매니저 — 설치 파일

루카스프로덕션 내부 직원용 도구입니다. 실행하려면 rauvfilm.com 계정이 필요합니다.
소스 코드는 비공개 저장소에서 관리합니다.

## 설치

- 윈도우: https://github.com/dlw1rma/rauvfilm-edit-manager-releases/releases/latest/download/lucas-production-manager-setup.exe
- 맥(Apple Silicon): https://github.com/dlw1rma/rauvfilm-edit-manager-releases/releases/latest/download/lucas-production-manager-setup.dmg

- 받은 파일을 실행하면 기존 버전(라우브 편집매니저) 위에 그대로 설치됩니다.
- "Windows의 PC 보호" 화면이 나오면 **추가 정보 → 실행**을 눌러 주세요.
- 설치한 뒤에는 앱이 새 버전을 알아서 알려 줍니다.
